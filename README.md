# فرانت عمومی به رسم دوکوهه

Next.js App Router، React، TypeScript strict و Tailwind CSS. این ریپو شامل بک‌اند PHP و پنل مدیریت نیست.

## اجرای محلی

Node.js نسخه ۲۲ یا جدیدتر:

```bash
npm ci
cp .env.example .env.local
npm run dev
```

در ویندوز: `Copy-Item .env.example .env.local`.

آدرس محلی: http://localhost:3000

```bash
npm run check
npm run format:check
npm run build
npx playwright install chromium
npm run test:e2e
```

## ساختار

- `src/app`: مسیرها، metadata و حالت‌های loading/error/not-found
- `src/features`: قابلیت‌ها؛ components، services، data، types و lib هر قابلیت در همان ماژول
- `src/components/ui`: کامپوننت‌های عمومی و مستقل
- `src/components/layout`: هدر، فوتر و ناوبری
- `src/lib/api`: ارتباط server-only با بک‌اند و اعتبارسنجی پاسخ‌ها
- `public/assets`: فایل‌های محلی استخراج‌شده از طرح Figma
- `tests/e2e`: تست تجربه کاربر در دسکتاپ و موبایل
- `.vscode`: تنظیمات و افزونه‌های پیشنهادی توسعه

## محدوده نسخه فعلی

خانه، فهرست و جستجوی دوره‌ها، فیلتر و مرتب‌سازی، جزئیات دوره، سبد خرید محلی، فهرست و جزئیات مقالات، درباره ما، تماس، فرم شماره موبایل و حالت‌های خطا پیاده شده‌اند.

ورود پیامکی، پرداخت، ثبت پیام، مشاهده درس‌های حفاظت‌شده، آزمون، گواهی و پنل شخصی هنوز پیاده/متصل نشده‌اند. دکمه‌ها موفقیت کاذب یا ورود ساختگی ایجاد نمی‌کنند. داده‌های فعلی نمونه‌اند؛ منتشر کردن سایت با داده‌های واقعی نیاز به جایگزینی آن‌ها دارد.

صفحه اصلی بر اساس فریم `1:1826` و اجزای آن پیاده شده است. تصاویر و آیکون‌های اصلی از فایل Figma صادر شده‌اند و URL موقت در کد نیست. فونت طرح Dana است؛ چون فایل مجاز فونت در دسترس نبود، Vazirmatn به شکل محلی استفاده شده است. برای تطابق نهایی باید فایل دارای مجوز Dana جایگزین شود. شمارش معکوس رویداد تا وجود تاریخ واقعی نمایش داده نمی‌شود. صفحات داخلی نسخه اولیه هستند و تطابق کامل تمام لایه‌های آن‌ها هنوز نهایی نیست.

## اتصال Laravel یا CodeIgniter

با `DATA_SOURCE=api` و `API_BASE_URL=https://backend.example/api/v1`، سرویس دوره‌ها پاسخ واقعی را دریافت می‌کند. در حالت API خطا به داده نمونه تبدیل نمی‌شود. قرارداد دقیق در `docs/backend-contract.md`.

این تنظیمات server-only هستند. هیچ secret یا access token را در متغیر `NEXT_PUBLIC_*` قرار ندهید. احراز هویت، کنترل دسترسی، قیمت نهایی، پرداخت، اعتبار آزمون و صدور گواهی باید در PHP تأیید شوند. localStorage فقط slug دوره‌های سبد خرید را نگه می‌دارد و مرجع قابل اعتماد نیست.

هدرهای پایه امنیتی فعال‌اند؛ CSP مبتنی بر nonce، CSRF و سیاست نشست باید هنگام پیاده‌سازی بک‌اند و انتخاب دامنه‌ها تکمیل شوند. امنیت نهایی محصول با فرانت تنها تأمین نمی‌شود.
